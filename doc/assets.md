# 免费素材列表

## 已使用素材

1. 背景音乐
   - 来源：[BitMidi](https://bitmidi.com/)
   - 描述：提供各种MIDI格式的背景音乐

2. 主界面地球
   - 来源：[Pixel Planet Generator](https://deep-fold.itch.io/pixel-planet-generator)
   - 描述：像素风格的行星生成器，用于创建主界面的地球图像

3. 部分物品、方块和生物的贴图
   - 来源：[Kenney's Assets](https://www.kenney.nl/assets)
   - 描述：提供多种游戏素材，包括物品、方块和生物的贴图

4. 丛林背景
   - 来源：[Jungle Pack by Jesse M](https://jesse-m.itch.io/jungle-pack)
   - 描述：丛林主题的背景图像和元素

注意事项：
- 部分素材的具体链接可能缺失，如果发现可以补充添加
- 如发现任何版权或许可证问题，请在GitHub上开启Issue或在QQ群内反馈

1. [Oak Woods环境包](https://brullov.itch.io/oak-woods)

2. [Jungle Pack丛林包](https://jesse-m.itch.io/jungle-pack)
